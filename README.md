# Gratia Gamage Portfolio

Personal portfolio for Gratia Gamage, Senior Software Consultant specializing in IFS Cloud and IFS Applications.

**Website:** https://gratiasew.github.io/GratiaGamage.github.io/

## Contents

- Professional profile and employment history
- IFS Cloud project milestones and expertise
- Credly links for IFS Cloud certifications
- Contact form that opens a prefilled email draft to `gratia12@gmail.com`
- Downloadable CV in PDF, RTF, and editable HTML formats

## Project Structure

- `index.html` - portfolio page
- `css/` - Bootstrap, template styles, and portfolio refresh styles
- `js/` - page interactions and contact form behavior
- `images/` - profile, project, and company logo assets
- `cv/` - CV files and certification documents

This is a static website published with GitHub Pages.
